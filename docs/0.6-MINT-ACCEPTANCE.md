# RiceExplorer 0.6 — Linux Mint acceptance matrix

0.6 remains an alpha until this matrix passes on a real desktop. Automated
Xvfb screenshots are useful regressions, **not** proof of actual pointer hit
targets, Wayland drag sources, screen-reader labels or removable-device safety.

## Before testing

- Back up important files. Test operations only on a disposable directory.
- Do not change live mounted directories, unplug devices during a write, or
  run destructive tests against real data. Keep Thunar installed.
- Capture session backend with `echo "$XDG_SESSION_TYPE"`. Test X11 and Wayland
  separately when both sessions are available; XWayland is **not** a native
  Wayland drag-source acceptance.
- Record exact RiceExplorer version (`rice-explorer --version`) and commit.
- Create a disposable local folder with files, folders, a symlink, a file
  without read permission, a long filename, and Unicode/spaces.

## Required interactive acceptance (repeat in all seven skins)

| Area | Steps | Expected |
| --- | --- | --- |
| File list | List/grid, sort by four columns, type filter, select with click/Ctrl/Shift | Consistent selection and no accidental mutations |
| Local navigation | Address, Back, Forward, Up, Home, F3 split, two-pane focus | Correct folder and active action target |
| Tabs | Duplicate, reorder, close, reopen, Ctrl+T/W, Ctrl+PageUp/PageDown, Ctrl+Shift+T | Restored paths and stable split tab identities |
| New window | Ctrl+Shift+N in a local folder, then close it | Original window/session is not overwritten |
| Native file drag | Drag between panels/folders, from desktop into Explorer | Copy uses no-overwrite conflict policy |
| **External drag-out** | Drag a local file from Explorer into Thunar, another GTK app | **BLOCKED** until native X11 and Wayland source backend is implemented and verified |
| Dialogs | New folder/rename, batch rename, paste options, Trash/delete confirmation, properties | Keyboard-focusable, Escape/Cancel have no filesystem side effects |
| Compact layout | 380×650, 700×470, normal size; all taskbars/sidebars/preview states | Primary actions and inputs remain reachable; no clipped active dialog |
| Accessibility | Keyboard-only access to every control; screen reader reads button and text-field labels | No focus trap, hidden action or indistinguishable focus |
| Error states | Permission denied, invalid destination, source vanished, offline network tab | Visible recoverable error; no misleading empty-folder success |
| Background I/O | Large folder scan, search cancel, slow remote/mount | UI remains responsive and worker results cannot overwrite newer navigation |
| App menu | Install from source and release bundle, search for RiceExplorer, launch with mouse and `gtk-launch rice-explorer` | Visible launcher starts installed binary without depending on `~/.local/bin` in session `PATH` |
| NAS discovery | With SMB advertising enabled on a LAN Synology, open **Discover NAS on network…**, click **Browse shares** | Server appears by name without manual address; shares open as read-only tab; absence/timeout doesn't freeze the UI |
| Saved NAS login | Connect with **Remember login in Linux keyring**; close/reopen dialog; select **Use saved login**; then **Forget saved login** | Password never appears in settings, argv or logs; can reconnect with explicitly retrieved credentials; forgetting removes keyring entry |
| Locked/missing keyring | Retry save with locked Secret Service / without `secret-tool` | Mount remains usable; storage failure is visible, no plaintext fallback or hang |

## Mounts and removable devices (read-only first)

1. With the device mounted, compare `findmnt -T /mnt/medien`,
   `timeout 8s ls -la /mnt/medien` and `stat -f /mnt/medien` against
   RiceExplorer's same-folder listing. **2026-11-05: owner rejected this
   acceptance** because `fs::read_dir` reports ENODEV. Do not call it passed
   until the Linux mount and Explorer results agree. A broken *child* mount
   must not hide healthy siblings; failure of the opened directory itself
   must be reported clearly.
2. Repeat on a disposable USB drive and GVfs/network mount. Verify mount
   labels and explicit confirmation before Unmount/Eject.
3. Only in an isolated disposable test, simulate disconnect while **idle**;
   use Retry and inspect visible error state. Never disconnect during writes.
4. Repeat encrypted archive compatibility tests using the independent fixture
   matrix in [`ARCHIVE-INTEROPERABILITY.md`](ARCHIVE-INTEROPERABILITY.md).

## Sign-off rules

- Record each test as **passed**, **failed with evidence**, or **not run** for
  each available desktop backend. Screenshots/logs must not contain passwords.
- A green Rust/CI build does not flip any unrun physical test to passed.
- The owner authorized **opt-in** Secret Service network login persistence in
  alpha.8. Verify that an unchecked box never saves a password, a successful
  checked mount stores only in the system keyring, and a failed mount stores
  nothing. Do not mark these checks passed without real Mint verification.
- Do not issue a stable `v0.6.0` tag until native external drag-out and all
  required physical tests pass or the release scope is explicitly revised.
