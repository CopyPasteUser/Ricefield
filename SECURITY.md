# Security policy

RiceExplorer is an experimental 0.x file manager. Please do not report security-sensitive bugs in public issues.

Use GitHub's **Report a vulnerability** option in this repository's Security tab (when enabled) to send a private report. Include the affected version, reproduction steps, expected impact and a safe test case. Do not include private files or credentials.

No fixed response or patch time is guaranteed. Do not use unverified builds for critical data without backups.
